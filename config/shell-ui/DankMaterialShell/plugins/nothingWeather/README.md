# Nothing Weather

NothingOS weather for DankMaterialShell — dot-matrix temperature, condition pill, hi/lo and a recolorable dot-style icon. Data from [open-meteo.com](https://open-meteo.com) (no API key); set a city or "lat,lon" in settings. Wide widgets switch to a horizontal layout automatically.
