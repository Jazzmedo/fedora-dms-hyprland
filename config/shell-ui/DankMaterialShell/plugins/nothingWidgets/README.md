# Nothing Widgets (DMS plugin)

NothingOS desktop widgets for DankMaterialShell — one plugin, five switchable
styles: **media player**, **weather**, **battery**, **calendar** and
**date & time**. Every style ships a light and dark card look, can follow the
shell palette automatically, and is adjustable from the plugin's settings
(style, theme, accent color, background opacity, weather location and units).

## Weather

The weather style queries [open-meteo.com](https://open-meteo.com) directly
(no API key). Set your coordinates in the plugin settings; defaults point at
Cairo.
