# fedora-nothing: DE-parity gap analysis + close every gap

**Findings first (what the analysis established):** The installer covers compositor, shell, theming, audio, network, bluetooth, portals, screenshots, default apps, and dev tooling well — but compared to a full DE it has zero coverage for: **keyring/secret service** (no gnome-keyring — saved-password storage broken), **power stack** (no upower → DMS battery widget is `import Quickshell.Services.UPower` and dead on bare Fedora; no power-profiles-daemon → DMS's enabled power-profile OSD is dead; installing upower also pulls udisks2 → removable-drive automount), **XDG autostart** (no dex/xdg-desktop-autostart.target — apps' autostart entries never run), **printing/scanning**, **firewall assurance**, **fwupd**, **xdg-user-dirs** (no Documents/Downloads on a Custom-OS install), **Dolphin extras** (no kio-extras/gvfs → no MTP/SMB/NFS; no ark/gwenview/okular/kate/kcalc/filelight — which the repo's own mimeapps and window rules already reference but never install), **idle/lock defaults** (hypridle/hyprlock rpms ship with no config; all DMS timeouts 0), plus small items (bluez-obex, satty, night-light keybind, wayscriber bound-but-not-installed). Live probe corroborated the session behavior; the doc will be based on repo facts only (the dev box runs Ubuntu, not Fedora — not usable as evidence).

## Part 1 — the shareable doc
Create `docs/de-parity.md` (matching docs/aquamarine-rgb-full.md tone, English, no machine-specific info):

- "Missing entirely" section ordered by usability impact, each with why it matters on a no-DE Fedora.
- "Present but misconfigured/referenced-but-not-installed" section (DMS battery/PPD daemons; mimeapps referencing okular/kwrite/gwenview; gnome-calculator window rules; wayscriber bind).
- "Deliberately out of scope" (IME — xkb us/ara covers it; screen reader; package GUI) with rationale.
- Prioritized roadmap P0/P1/P2 mapping each gap to the component it became.

## Part 2 — implement in the repo (following lib/components.sh registry pattern)
**Core additions (base packages):**
- `gnome-keyring` + `gnome-keyring-pam`; SDDM PAM lines (auth optional + session) in /etc/pam.d/sddm{,-autologin,-greeter} for unlock-at-login; doctor check for the keyring on the session bus.
- `upower` + `power-profiles-daemon` (fixes DMS battery widget + power-profile OSD + udisks2 automount); doctor check.
- `dex` + start it in the hyprland.start hook: `dex -a -s /etc/xdg/autostart/:~/.config/autostart/` (guarded so re-runs don't double-start).

- Dolphin/utility stack: `kio-extras gvfs gvfs-mtp gvfs-smb gvfs-nfs gvfs-gphoto2 gvfs-archive ark gwenview okular kate filelight kcalc` (mimeapps fallbacks start actually working).

**New optional components (checklist, off unless noted):**
